# explorer-vim-ahk

Vim-style navigation for Windows Explorer, written in AutoHotkey v2.
Управляй Проводником Windows как в Vim: режимы, счётчики, комбинации клавиш, переключение между панелями.

> Tested on Windows 10 (classic ribbon Explorer). Windows 11 may need tweaks.

## Установка

1. Установи [AutoHotkey v2](https://www.autohotkey.com/)
2. Скачай `explorer_vim.ahk`
3. Запусти двойным кликом (для автозапуска положи ярлык в `shell:startup`)

Работает только в окне Проводника. Раскладка не важна (клавиши привязаны по VK-кодам).

## Режимы

| Режим | Как войти | Что делает |
|-------|-----------|------------|
| NORMAL | по умолчанию / `Esc` | буквы работают как команды |
| VISUAL | `v` | выделение через `j` / `k` |
| INSERT | `i` | обычный набор (поиск по первой букве) |

Режим показывается подсказкой внизу окна.

## Клавиши

### Движение

| Клавиши | Действие |
|---------|----------|
| `j` / `k` | вниз / вверх |
| `h` | папка выше |
| `l` / `o` | открыть |
| `5j`, `3k` | движение со счётчиком |
| `gg` / `G` | в начало / в конец |
| `12G` | к 12-му элементу |
| `0` | в начало |
| `Ctrl+d` / `Ctrl+u` | страница вниз / вверх |
| `H` / `L` | назад / вперёд по истории |
| `-` | папка выше |

### Панели

| Клавиши | Действие |
|---------|----------|
| `gn` | боковая панель (навигация `h j k l`, `o` открыть) |
| `gl` | адресная строка |
| `gr` | лента (`h` / `l` по вкладкам, `o` выбрать) |
| `/` | поиск |
| `gf` | вернуться к списку файлов |
| `Tab` | переключение между панелями |
| `Esc` | вернуться в список |

### Действия

| Клавиши | Действие |
|---------|----------|
| `yy` | копировать |
| `dd` | вырезать |
| `p` | вставить |
| `x` | удалить в корзину |
| `X` | удалить навсегда |
| `r` | переименовать |
| `a` | новая папка |
| `u` / `Ctrl+r` | отменить / вернуть |
| `V` | выделить всё |
| `Space` | отметить элемент |
| `yp` | скопировать путь |
| `zh` | показать / скрыть скрытые файлы |
| `zr` | свернуть / развернуть ленту |
| `R` | обновить |

`Ctrl+Alt+V` включает и выключает весь скрипт.

## Известные ограничения

- Лента (`gr`) работает капризно: в ней доступны только `h j k l o`, подсказки Alt недоступны.
- Если боковая панель скрыта, `gn` ничего не сделает.
- Классы окон рассчитаны на Windows 10.

## English summary

Modal (NORMAL / VISUAL / INSERT) Vim-like keybindings for Windows Explorer: `hjkl` movement, counts (`5j`), `gg` / `G`, `yy` / `dd` / `p`, panel switching (`gn` sidebar, `gl` address bar, `gr` ribbon, `/` search). Requires AutoHotkey v2. Toggle with `Ctrl+Alt+V`.
